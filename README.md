# Роберт Мадышев (@RKOTOFF) - Личный сайт

Персональный сайт-визитка архитектора приватных систем.

## Стек технологий
- **HTML5** — Структура
- **Tailwind CSS** (через CDN) — Стилизация и анимации
- **Vanilla JavaScript** — Интерактивность (галерея, модальные окна, мобильное меню)

## Функционал
- Адаптивный дизайн (Mobile/Desktop)
- Анимации появления и взаимодействия
- Галерея проектов с модальными окнами
- Интерактивная временная шкала (Timeline)

## Запуск
Сайт работает как статика. Для просмотра достаточно открыть файл `index.html` в браузере или разместить его на GitHub Pages.
